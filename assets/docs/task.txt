The current code uses docker exec ollama ollama [command] which no longer works. It needs to be changed to call the Ollama REST API directly at http://localhost:11434/api/.

    Models are not loading when clicking the "Load Model" button

    Status shows "Waiting for service..." even when Ollama is running

    The ollama_api.php and force_reload_model.php files still have Docker-specific code
