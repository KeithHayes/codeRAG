The tas is to produce a clean, readable transcript with accurate speaker turns and labels.  Development is iterative so you should evaluate the files and make changes to accomplish the rules.  Currenttly the rules are incorrectly implemented.

INPUT: A plain, transcript cleaned of timestamps.

The task for this session is to perform the next step in the iterative development of this project and correct the transcript pipeline so that a clean speaker labeled transcript is produced with transcript timestamps removed.


RULES:


1. **Clean disfluencies.**  
   - Remove filler words ("uh", "um", "ah", "you know"), stutters/repeats ("I I I", "andor"), and false starts.  
   - Do NOT rephrase, summarize, or reorder any words. Only remove the disfluencies.

2. **Correct unambiguous misspellings.**  
   - Fix obvious misspellings of proper names and places when the correct form is clear from context (e.g., "Dimmitri" → "Demetri").  
   - If ambiguous, leave as-is.

3. **Identify and label speakers.**  
   - Infer speaker names from the transcript itself (e.g., someone says "This is X" or "I'm Y"). Use those names as labels.  
   - For speakers that cannot be identified, use generic labels like "Speaker 1", "Speaker 2", etc., in order of first appearance.  
   - Do NOT hardcode any specific names from example transcripts.

4. **Format speaker turns.**  
   - Each turn begins with the speaker label followed by a colon and a space, then the spoken text:  
     `SpeakerName: The spoken text.`  
   - After each turn, add one blank line before the next speaker's label.

5. **Preserve all content.**  
   - Do not delete any words except fillers and non-spoken timestamp lines.  
   - Keep all numbers, dates, quoted text, and attributions (e.g., "police allege").  
   - Do NOT summarize, paraphrase, or condense.  
   - If a word is unintelligible, mark it as `[inaudible]`.

OUTPUT: Only the cleaned, labeled transcript with blank lines between turns. No extra commentary.
